\# Proyecto Julia: Entorno Aislado y Gráficos



Este es mi primer proyecto configurado con el gestor de entornos nativo de Julia.



\## Herramientas utilizadas

\* \*\*Julia\*\* 1.13.2

\* \*\*Plots\*\* para visualización de datos

\* \*\*Git\*\* para control de versiones



\## Cómo reproducir este proyecto

1\. Clonar el repositorio.

2\. Abrir la consola de Julia en esta carpeta.

3\. Presionar `]` para entrar al modo `pkg>` y ejecutar `instantiate`.

4\. Ejecutar el código para generar la gráfica.
